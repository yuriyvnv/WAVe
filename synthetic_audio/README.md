# Synthetic Audio Generation

This directory contains utilities for creating synthetic data that replicates the word distribution found in Common Voice 17 for Portuguese and Dutch languages.

## Overview

- **Word Distribution Replication**: Create synthetic transcripts matching Common Voice 17 word patterns
- **Two-Stage Generation**: Text generation followed by audio synthesis
- **Language-Specific**: Separate processing for Portuguese and Dutch
- **Dataset Integration**: Compatible with training pipeline requirements

## Files

### `generation.py`
Generates synthetic transcripts using GPT-4o-mini based on Common Voice 17 samples.

**Key Features:**
- Analyzes word distribution patterns from Common Voice 17
- Uses GPT-4o-mini to generate synthetic transcripts
- Maintains linguistic patterns and vocabulary distribution
- Creates transcripts that match target language characteristics

**Process:**
1. Load Common Voice 17 samples for target language
2. Analyze word frequency and distribution patterns
3. Generate synthetic transcripts using GPT-4o-mini
4. Ensure generated text matches original distribution

### `audio_generation.py`
Converts synthetic transcripts to audio using Text-to-Speech models.

**Key Features:**
- Uses OpenAI TTS models (`tts-1`)
- Processes synthetic transcripts generated by `generation.py`
- Creates audio files with proper sampling rates (16kHz)
- Handles batch processing for large datasets

**Configuration:**
```python
DATASET_REPO = "ANONYMOUS_USER/synthetic_transcript_nl"
TTS_MODEL = "tts-1"
HUB_REPO_AUDIO = "ANONYMOUS_USER/synthetic_transcript_nl"
```

### `verify_dataset.py`
Validates the quality and integrity of generated synthetic datasets.

**Key Functions:**
- Verify audio file integrity and format
- Check transcript-audio correspondence
- Validate word distribution preservation
- Generate quality assessment reports

## Workflow

1. **Analysis**: Extract word distribution from Common Voice 17 samples
2. **Text Generation**: Use GPT-4o-mini to create synthetic transcripts matching distributions
3. **Audio Synthesis**: Convert synthetic transcripts to audio using TTS
4. **Verification**: Validate quality and distribution preservation
5. **Integration**: Prepare datasets for multimodal training

## Usage

### Generate Synthetic Transcripts

```bash
# Generate synthetic transcripts matching Common Voice patterns
python generation.py
```

### Generate Audio from Transcripts

```bash
# Convert synthetic transcripts to audio
python audio_generation.py
```

### Verify Generated Data

```bash
# Validate synthetic dataset quality
python verify_dataset.py
```
